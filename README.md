# Mapas personalizados – Call of Duty: Black Ops 3

Proyecto web desarrollado como parte de mi portfolio personal de Desarrollo de Aplicaciones Web (DAW).

El objetivo del proyecto es recomendar y presentar mapas personalizados de Call of Duty: Black Ops 3 disponibles en Steam Workshop, aplicando buenas prácticas de desarrollo frontend y SEO técnico.

## Tecnologías utilizadas
- HTML5 semántico
- CSS3 (diseño responsive)
- JavaScript (interacción y filtrado dinámico)

## Funcionalidad principal
- Listado de mapas personalizados con información descriptiva
- Sistema de filtrado y paginación
- Diseño responsive para distintos dispositivos
- Estructura semántica orientada a accesibilidad y SEO

## Enfoque del proyecto
Proyecto orientado a portfolio, centrado en:
- Organización del código frontend
- Optimización SEO básica
- Buenas prácticas de estructura HTML
- Experiencia de usuario

## Estado del proyecto
Funcional y en evolución. Se trata de un proyecto personal de carácter formativo.

## Nota
Los recursos gráficos utilizados se incluyen únicamente con fines demostrativos.
